# DSH-плагины

Плагины для DeepSeek Harness Desktop: голосовой режим, русский интерфейс, анонимные диалоги,
удаление сессий и память агента. Всё работает локально, без облака, и ставится из npm.

Репозиторий: <https://github.com/apopov-app/dsh-plugins> · npm-скоуп `@app-apopov`.

## Что внутри

| Плагин | Что даёт |
|---|---|
| [`voice-assistant`](voice-assistant/README.md) | Голосовой режим: кнопка с микрофоном в диалоге, распознавание речи на устройстве, озвучка ответов, перебивание голосом, выбор голоса и темпа. |
| [`locale-ru`](locale-ru/README.md) | Русский язык интерфейса: язык `ru` и переводы всех поверхностей клиента — сайдбар, диалог, настройки, плагины, терминал. |
| [`anonymous-session`](anonymous-session/README.md) | Кнопка «Новая анонимная сессия»: обычный диалог, но без выбора папки проекта. |
| [`delete-session`](delete-session/README.md) | Пункт «Удалить диалог навсегда» в меню сессии — стирает журнал без возможности восстановить. |
| [`engram-memory`](engram-memory/README.md) | Память агента: сохраняет решения и находки, ищет их в новых диалогах; память проекта лежит в самой папке и переезжает вместе с ней, плюс общий слой для всех проектов. |

## Установка

Поставьте нужные плагины из npm:

```sh
dsh plugin --profile desktop add @app-apopov/dsh-voice-assistant
dsh plugin --profile desktop add @app-apopov/dsh-locale-ru
dsh plugin --profile desktop add @app-apopov/dsh-anonymous-session
dsh plugin --profile desktop add @app-apopov/dsh-delete-session
dsh plugin --profile desktop add @app-apopov/dsh-engram-memory
```

То же самое в интерфейсе: **Plugins → Add plugin** и имя пакета.

После установки плагинов обновите страницу Harness (⌘R); части, которые работают в фоне,
включаются при следующем запуске приложения.

Удаление: `dsh plugin --profile desktop remove @app-apopov/dsh-<плагин>`.

## Как пользоваться

**voice-assistant** — справа в диалоге появляется кнопка с микрофоном. Нажмите и говорите, отпустите кнопку —
реплика отправится; ответ озвучивается. Перебить ассистента можно, просто начав говорить.
Голос, интонация и темп настраиваются в Settings → General и на странице плагина.

**locale-ru** — в выборе языка клиента появляется «Русский». Строки, которых нет в переводе
(например, после обновления клиента), показываются по-английски.

**anonymous-session** — под кнопкой «Новая сессия» есть «Новая анонимная сессия»: диалог
открывается сразу, папку проекта выбирать не нужно.

**delete-session** — меню «...» у строки диалога → «Удалить диалог навсегда». Удаление требует
второго клика и необратимо.

**engram-memory** — нужен установленный [`engram`](https://github.com/Gentleman-Programming/engram)
(`brew install gentleman-programming/tap/engram`). Дальше ничего настраивать не нужно: агент сам
сохраняет решения и находки. Проверка — скажите «запомни, что проверка памяти — лапсанг», начните
новый диалог и спросите про это.

## Требования

- DeepSeek Harness Desktop, версия клиента **0.2.1-rc.5**. Собирать ничего не нужно.
- `voice-assistant` при первом использовании скачивает модели голосов и распознавания — нужен
  интернет, дальше всё офлайн.
- `engram-memory` требует установленного `engram`; память хранится в `~/.engram/engram.db`.

## Ограничения

- Локализация переводит словари клиента: описания инструментов и названия плагинов из метаданных
  остаются английскими, а новые строки после обновления клиента — тоже.
- «Анонимная» сессия означает «без папки проекта»: диалог обычный, пишется в журнал и виден в
  сайдбаре в группе «Анонимные сессии».
- Память проекта лежит в его папке (`.dsh-memory`): удалите папку — уйдёт и память, скопируете — у копии будет своя. Общий слой (`scope: "global"`) хранится отдельно и никуда не переезжает.
